# Неделя — плагин Agents Hub

Раз в неделю — разбор прошлой недели. По умолчанию понедельник 9:00 по местному времени компьютера; день, время и
пояс меняются во вкладке «Неделя» → «Изменить» (или хабу: `hub post week-recap "расписание: вт 10:30 Europe/Berlin"`).

- **Задачи** — ваши человеческие задачи, а не шаги агентов: что сделано, что в работе, что брошено, с первого раза или
  с переделками; закрытые за неделю задачи Jira.
- **Эффективность связки** — доля задач с первого раза, сколько ушло вашего времени (сообщения, формы, переделки), сколько
  вы ждали результат.
- **Рекомендации** — каких агентов или субагентов завести, что поставить, в каком формате давать указания.

Как работает: процесс плагина читает журнал хаба за неделю (только чтение) и собирает сводку; разбор пишет агент
`analyst`, если он есть, иначе хаб. Готовый разбор приходит в Telegram и во вкладку «Неделя»; разбор не пришёл за 6 часов —
приходят одни цифры. Jira — через MCP `atlassian` хаба, если он подключён и выдан тому, кто разбирает.

Своё плагин держит в папке состояния хаба: `week-recap/<неделя>/digest.md` (сводка), `recap.md` (разбор).
Собрать сводку руками, ничего не отправляя: `python3 main.py --week 2026-W41 --dry` (с `PYTHONPATH` на код хаба).

Поставить: «Настройки» → «Плагины» → week-recap. Первый разбор — прошлой недели, сразу после установки.
